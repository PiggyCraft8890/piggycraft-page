# PiggyCraft — Portfolio

Portfolio one-page en HTML/CSS/JavaScript, prêt pour GitHub Pages.

## Fichiers
- `index.html` : contenu et structure
- `style.css` : design responsive et animations
- `script.js` : interactions, lecteur vidéo et menu mobile

## Publication sur GitHub Pages
1. Décompresse l'archive.
2. Envoie les trois fichiers à la racine du dépôt GitHub qui sert ton site.
3. Dans **Settings → Pages**, vérifie que GitHub Pages publie depuis la bonne branche et le dossier `/ (root)`.
4. Une fois publié, le site sera accessible à l'adresse configurée.

## Adresse piggycraft.ca/portfolio
Pour servir ce portfolio sous `piggycraft.ca/portfolio`, place les fichiers dans un dossier `portfolio/` du dépôt qui publie déjà `piggycraft.ca`, ou configure ton routage/déploiement pour que ce chemin pointe vers ce dossier. Un dépôt GitHub Pages de projet séparé utilise normalement son propre chemin de projet et ne prend pas automatiquement en charge un sous-chemin personnalisé sur ton domaine.

## Personnalisation
- Remplace `Projet vidéo 01/02/03` dans `index.html` par les vrais titres des vidéos.
- Modifie les textes de présentation directement dans `index.html`.
- Les couleurs sont définies au début de `style.css` (`--pink` et `--blue`).
- Le lien YouTube et le lien Discord sont déjà ajoutés.

Les miniatures sont chargées depuis YouTube et les vidéos s'ouvrent dans une fenêtre intégrée. Une connexion Internet est nécessaire pour les polices, miniatures et vidéos.
